# 📊 Power BI Dashboards Portfolio

Welcome to my Power BI Dashboard Portfolio! This repository showcases interactive data visualization projects designed to transform data into meaningful insights and support data-driven decision-making.

## 🏥 1. Kauvery Hospital Emergency & Clinical Operations Dashboard

**Objective:** To monitor emergency department performance and healthcare operations through an interactive dashboard.

**Key Performance Indicators (KPIs):**
- Total Patients
- Bed Occupancy Rate
- Left Without Being Seen (LWBS) Rate
- Average Waiting Time
- Critical Triage Cases

**Features:**
- Interactive filters for location, department, and shift
- KPI cards for monitoring emergency department performance
- Dark-themed command-center interface
- Visual insights into patient flow and operational efficiency

**Tools Used:** Microsoft Power BI, Data Visualization, Data Analytics

## 🤖 2. Stark Industries JARVIS Mission Intelligence Dashboard
